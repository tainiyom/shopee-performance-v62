## สิ่งที่เพิ่มใน Version 62
1. **สร้างแผนอัตโนมัติ** (ปุ่ม 🎯 แผนเป้าหมาย): ใส่เป้าทั้งเดือน วันแคมเปญ และเป้าวันแคมเปญ ระบบกระจายส่วนที่เหลือให้วันปกติ (เท่ากัน หรือไล่ระดับต้นเดือนน้อย → ปลายเดือนมาก) วันแคมเปญถูกบันทึกในแผน และใช้คำนวณ “ต้องทำต่อวัน” ในรายงานแผน
2. **แจ้งเตือนวันที่ยังไม่ได้บันทึก**: แถบบน Dashboard แสดงวันที่ไม่มีรอบรายวันใน 31 วันล่าสุดถึงเมื่อวาน กดวันที่เพื่อตั้งฟอร์มเป็นวันนั้นทันที
3. **ROI เทียบเป้าในตารางประวัติ**: ✓ ถึงเป้า / ▼ ต่ำกว่าเป้า พร้อมสรุปจำนวน และปุ่ม “ดูเฉพาะรอบที่ต่ำกว่าเป้า” (เป้า = ค่าในรอบนั้น หรือเป้า ROI ในแผนของเดือนนั้น)
4. **วางข้อมูลจาก Seller Centre** (ปุ่ม 📋 ในฟอร์ม): วางข้อความที่คัดลอกมา ระบบจับยอดขาย (ยืนยัน/ชำระ), ยอดขายตามที่มา, ยอดขายจาก Shopee Ads, ค่าใช้จ่าย/ยอดขายรายช่องทางโฆษณา และช่วงวันที่ แสดงตัวอย่างให้ตรวจ/แก้ก่อนเติมลงฟอร์ม
   - ตาราง Shopee Ads ควรคัดลอกหัวตารางมาด้วย (คอลัมน์ “ค่าใช้จ่าย” และ “ยอดขาย”) ถ้าไม่มีหัวตาราง ระบบถือว่าค่าที่น้อยกว่าคือค่าใช้จ่าย
5. แสดงวันที่สำรอง CSV ล่าสุดใต้ปุ่มบันทึก เตือนเมื่อเกิน 7 วัน
6. **นำเข้า Excel จาก Seller Centre** (ปุ่ม 📊 ในฟอร์ม หรือลากไฟล์มาวางบนฟอร์ม): ไฟล์ `*.shopee-shop-stats.YYYYMMDD-YYYYMMDD.xlsx`
   - อ่านแท็บ “ที่มาของการเข้าชม (ยืนยันแล้ว)” และ “(ชำระเงินแล้ว)”: ยอดขายทั้งร้าน, ยอดขายแบ่งตามที่มา 4 ช่อง, ยอดขายจาก Shopee Ads, และตาราง “โฆษณา Shopee Ads” (ค่าโฆษณา + ยอดขาย รายช่องทาง)
   - อ่านช่วงวันที่จากไฟล์ ถ้ามีรอบวันที่นั้นอยู่แล้วจะเปิดรอบนั้นแก้ไข (เก็บ CPAS หมายเหตุ TOP 5 เดิมไว้) ถ้ายังไม่มีจะเปิดเป็นรอบใหม่
   - เลือก 1 ไฟล์ = เติมลงฟอร์มให้ตรวจแล้วกดบันทึกเอง · เลือกหลายไฟล์ = บันทึกทุกวันทันที (ถามยืนยันก่อน)
   - **TOP 5 สินค้า** จากแท็บ “ส่วนแบ่งรายการสินค้า (ยืนยันแล้ว)” และ “(ชำระเงินแล้ว)”: รวมยอดขาย (THB) และจำนวนสินค้าทั้งหมดของสินค้าเดียวกัน (ตามรหัสสินค้า) จากทุกที่มา (หน้ารายละเอียดสินค้า, Live, วิดีโอ, พาร์ทเนอร์) แล้วจัดอันดับ TOP 5 ยอดขาย และ TOP 5 จำนวนชิ้น
     - ไฟล์ให้แค่ 5 อันดับแรกต่อที่มา ตัวเลขรวมจึงเป็นยอดจาก “ที่มาที่ติด TOP 5” เท่านั้น อาจต่ำกว่ายอดจริงของสินค้านั้นเล็กน้อย
     - ชื่อ รูป และลิงก์: ถ้าสินค้านั้นเคยกรอกไว้ในคลังสินค้า ใช้ของเดิม · ลิงก์สินค้าใหม่สร้างจากรหัสร้านที่เรียนรู้จากลิงก์ที่เคยกรอก (วางลิงก์สินค้าสักครั้ง ครั้งต่อไปสร้างให้เอง)
   - CPAS ไม่มีในไฟล์ ต้องกรอกเอง · ตัวอ่าน Excel ฝังในหน้าเว็บ ไม่ต้องต่อเน็ต

## ฟีเจอร์เดิมที่ยังอยู่
- กรอกรายวัน/สัปดาห์/เดือน/กำหนดเอง, แก้ไข/ลบ, นำเข้า–ส่งออก CSV (แยกร้าน/ทุกร้าน), หลายร้าน
- 2 ชุดข้อมูล: ยอดยืนยันแล้ว / ยอดชำระแล้ว
- ช่องทางโฆษณาเปิด/ปิดต่อร้าน, ยอดขายตามที่มา, TOP 5 (ยอดขาย/จำนวนชิ้น) + คลังสินค้า
- กราฟแนวโน้ม, กล่องรายละเอียดลอย, ดูรายวันในสัปดาห์, แผน/รายงานแผน/scorecard, หมายเหตุ + แท็ก, กำไรสุทธิ
